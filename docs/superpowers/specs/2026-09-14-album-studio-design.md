# 相册工作台 v1 设计说明

## 目标

为个人摄影作品发布提供本地图库和作品排版工具。原图不复制、不迁移；相册和作品只保存引用，精确重复的原图只计为一个照片资产。

## 领域模型

- `media_assets`：按 SHA-256 标识的照片内容，保存尺寸、EXIF 和收藏状态。
- `media_locations`：照片在磁盘上的物理路径；一个资产可有多个位置。
- `albums` / `album_items`：相册及照片引用，同一资产可在多个相册复用。
- `works` / `pages` / `layers`：相册下的多套排版版本、页面和图片/文字图层。
- `templates`：内置和自定义模板，使用版本化 JSON 保存。
- `source_roots` / `ignored_paths`：监听目录及用户主动移除的路径。

## 关键规则

- 相同内容的文件只生成一个资产；重命名或移动后按哈希恢复引用。
- 唯一位置被原地覆盖时保留资产 ID 和相册引用；覆盖成已有内容时合并关联。
- 来源目录离线时保留索引，不把照片批量标记为缺失。
- 从相册或图库移除只删除数据库记录；删除原图必须二次确认并使用系统回收站。
- 编辑器图层坐标使用 0–1 归一化值，模板可适配不同长边导出尺寸。
- 多页作品逐页导出；长图按相同宽度和设定间距合并，最大高度为 65,535 px。

## 进程与安全

- Electron 主进程独占 SQLite、文件扫描、缩略图、导出和回收站操作。
- 渲染进程无 Node 权限，通过类型化 `window.albumApi` 调用 IPC。
- 照片通过 `album-media://` 受控协议按资产 ID 访问，不向界面暴露任意文件读取能力。
- SQLite 使用 WAL；后台扫描批量写入，缩略图按需生成并执行 LRU 容量清理。

## 验证

- 单元与集成测试覆盖资产合并、原图覆盖、重命名恢复、多相册引用、作品页面、EXIF 搜索、缩略图缓存、备份和分页/长图导出。
- 无头 Electron 运行时测试覆盖真实目录扫描、重复文件、自定义协议、作品创建和 1080×1440 JPEG 导出。
- 发布验收同时验证 `dist\win-unpacked` 免安装目录和 NSIS 安装包。
